Triangle heatmap (ASV x ASV correlation matrix). This figure draws on the per-sample relative-abundance table (model_inputs/abundances.json, samples H-Qa across the operational time course) joined to the ASV display-name map (iterativeIDs.json) and pre-filtered against significantly_connected_organisms.json so that only ASVs with a meaningful presence in the dataset enter the matrix. Pairwise rank correlations between every pair of surviving ASVs are computed with Spearman's rho (df.corr('spearman')) and accompanied by per-pair p-values from scipy.stats.spearmanr; the resulting p-value vector is then corrected for multiple testing with Benjamini-Hochberg FDR (multipletests(..., method='fdr_bh', alpha=0.05)), and significant pairs (q < 0.05) are annotated with asterisks on the final figure. The reasoning behind this stack is that ASV abundance distributions are strongly non-normal, zero-inflated, and dominated by a few high-abundance taxa, so a rank-based monotone test (Spearman) is far more robust than Pearson; because every additional ASV multiplies the number of simultaneous tests quadratically, an FDR correction (rather than the more conservative Bonferroni) is used to retain power while still bounding the expected fraction of false discoveries among the asterisked pairs. Plotting is handled by seaborn.clustermap on a coolwarm_r colormap centered at rho = 0, with hierarchical clustering on rows and columns so that co-varying ASV groups fall along the diagonal; an upper-triangle Boolean mask (np.triu(..., k=1)) blanks the redundant half of the symmetric matrix, leaving the single triangle from which the figure takes its name and saving the file to abundance_heatmaps/abundance_correlations_one_triangle.png.

Top-10 ASV abundance heatmap. The input is again the per-sample abundance matrix in model_inputs/abundances.json, but here it is grouped by sample day and the *union* of the ten most abundant ASVs *per day* is taken so that taxa which dominate only briefly are not lost; the resulting wide table is decorated with phylum-level taxonomy from iterativeID_levels.json and Phylum_color_map.json for the row colors, and a per-day Shannon diversity index is computed from the full (unfiltered) community to be overlaid above the columns. No inferential statistics are applied -- the figure is purely a visualization of relative abundance -- but the abundances are log10-transformed before plotting and rows are reordered by hierarchical linkage on the log-scale data. The log transform is the key intuitive step: methanogen and bacterial abundances span several orders of magnitude across the time course, so a linear color scale would saturate on the 1-2 dominant taxa and render every other row indistinguishable; log scaling compresses the dynamic range so that a 10x shift in a low-abundance organism is as visually salient as a 10x shift in a high-abundance one, while pairing this with the per-day "top-10-union" selection keeps the row count tractable without discarding transiently important taxa. The figure itself is rendered with a custom LinearSegmentedColormap (navy gradient) and a TwoSlopeNorm anchored at log10(0.1 %) so the color midpoint corresponds to a biologically meaningful "rare-vs-detectable" threshold; row and column color bars encode phylum and the Shannon trace, and the file is saved as abundance_heatmaps/top_10_asvs_(%_abundance).png.

Co-occurrence network. The network is built from the same abundances.json table -- restricted to ASVs detected (>0) in at least three samples to suppress one-off sequencing artifacts -- together with taxonomy.json/iterativeIDs.json for node metadata. For every surviving ASV pair the pipeline computes both a raw co-occurrence count (the number of samples in which both members are simultaneously present) and a Spearman rho with its p-value; p-values are then BH-FDR-corrected at alpha = 0.05 and only edges that survive (q < 0.05) are added to the graph. Node size is scaled by mean relative abundance and edge color is the coolwarm_r mapping of rho, so positively co-varying pairs appear blue and antagonistic pairs red. The intuition is that pairwise correlations alone tend to produce hairball networks dominated by spurious edges from low-prevalence ASVs, so the prevalence pre-filter, the rank-based correlation, and the FDR threshold act as three independent noise filters: prevalence removes statistically uninformative columns, Spearman insulates against outlier-driven Pearson artifacts, and FDR bounds how many of the surviving edges are expected to be false positives; sizing nodes by abundance and coloring by phylum then preserves the biological signal that "who interacts with whom" is conditioned on "who is actually there." Plotting uses NetworkX with a spring layout (k = 4.0, 300 iterations) so highly connected modules cluster spatially, on a 40 x 30-inch canvas; nodes whose mean relative abundance exceeds 0.2 % are labeled directly to keep the figure legible, and the result is written to cooccurrence_network_p_value_FDR.png.

Operational correlations heatmap. The inputs are a family of modeling_files/correlations/ASV_correlations_all_relevant_samples_*.json files -- one per operational metric (H2/CO2/CH4 delivery and breakthrough rates, conversion efficiencies, media chemistry, waste-effluent chemistry, pH, SRT, etc.) -- produced upstream by _correlate_all_params_050526.py, which Spearman-correlates every ASV's time series against each operational metric's interpolated time series from model_inputs/measurements/Summary_interpolated.csv. In the heatmap script those per-metric rho/p tables are concatenated into an ASV x metric matrix; p-values are BH-FDR-corrected *within each metric column* at alpha = 0.05, non-significant cells are blanked, and the "reduced" version then drops any ASV row whose entries are all zero/NaN after filtering. Per-metric (rather than global) FDR is the deliberate choice here: each operational variable represents a distinct biological hypothesis (e.g., "does this taxon track H2 delivery?") and bundling them all into one combined null would either over-penalize hypotheses with many true signals or under-penalize ones with few, while the per-column correction lets each metric's discoveries be interpreted on its own footing; the rank correlation again handles the heavy-tailed abundance distributions and the row-zero filter strips taxa that contribute no significant signal anywhere, which is what makes the reduced figure interpretable at print size. The figure is drawn with seaborn.clustermap using a coolwarm_r cmap and TwoSlopeNorm centered at rho = 0 (range -0.8 to +0.8), with rows hierarchically clustered so functionally similar ASVs group together while columns are held in their fixed operational-metric order, individual cell rho values overlaid as text, and the output saved to correlations_heatmap_reduced.png/.svg.
